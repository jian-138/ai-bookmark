# Chrome 扩展安装和测试指南

## 📦 安装步骤

### 1. 准备工作
确保已完成后端服务配置：
```bash
# 启动后端服务
uvicorn main:app --host 0.0.0.0 --port 8000 --reload
```

### 2. 加载 Chrome 扩展
1. 打开 Chrome 浏览器
2. 访问 `chrome://extensions/`
3. 开启右上角的"开发者模式"
4. 点击"加载已解压的扩展程序"
5. 选择 `chrome-extension` 文件夹
6. 扩展加载成功后，会在工具栏显示图标

### 3. 验证安装
1. 点击 Chrome 工具栏上的扩展图标
2. 应该看到登录界面
3. 输入测试账号：
   - 用户名：`test`
   - 密码：`test123`

## 🐛 常见问题解决

### 问题1: 登录失败
**症状**: "无法连接到服务器，请检查后端服务是否正在运行"

**解决**:
1. 确保后端服务正在运行：
   ```bash
   python test_backend.py
   ```
2. 检查 Chrome 扩展配置：
   - 打开 `chrome-extension/config.js`
   - 确认 `apiUrl` 设置为 `http://localhost:8000`
3. 重新加载扩展：
   - 访问 `chrome://extensions/`
   - 点击扩展的"重新加载"按钮

### 问题2: 收藏按钮不显示
**症状**: 选中文本后没有浮动收藏按钮

**解决**:
1. 检查扩展权限：
   - 访问 `chrome://extensions/`
   - 确保扩展有"读取和更改网站数据"权限
2. 刷新页面重试
3. 检查浏览器控制台是否有错误

### 问题3: 快捷键无效
**症状**: 按快捷键没有反应

**解决**:
1. 确保扩展已启用
2. 检查是否有其他扩展占用了相同快捷键
3. 在扩展设置中重新配置快捷键

### 问题4: 网络错误
**症状**: "网络连接失败"或"请求超时"

**解决**:
1. 检查网络连接
2. 确认后端服务地址正确
3. 检查防火墙设置
4. 查看详细错误信息：
   - 打开扩展的开发者工具
   - 查看 Console 和 Network 标签页
