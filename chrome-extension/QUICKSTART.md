# 🚀 快速启动指南 - Chrome 插件周报功能

## 5 分钟快速体验

### 步骤 1：启动后端服务（1 分钟）

```bash
cd f:\ai-bookmark
python main.py
```

等待看到：
```
INFO:     Uvicorn running on http://0.0.0.0:8000
```

### 步骤 2：加载插件（1 分钟）

1. 打开 Chrome 浏览器
2. 访问 `chrome://extensions/`
3. 开启右上角"**开发者模式**"开关
4. 点击"**加载已解压的扩展程序**"
5. 选择文件夹：`f:\ai-bookmark\chrome-extension`
6. 看到"AI 书签收藏助手"插件已添加

### 步骤 3：登录插件（1 分钟）

1. 点击浏览器工具栏中的插件图标
2. 使用测试账号登录：
   - 用户名：`test`
   - 密码：`test123`
3. 点击"登录"按钮

### 步骤 4：打开周报收藏（30 秒）

1. 在插件主界面底部
2. 点击"**🔍 搜索**"按钮
3. 弹出周报收藏页面

### 步骤 5：开始使用（1 分钟）

#### 查看统计
- 关键词数量
- 收藏数量
- 内容数量

#### 搜索内容
1. 在搜索框输入：`Python`
2. 点击搜索按钮
3. 查看搜索结果

#### 点击关键词
1. 点击"🔥 热门关键词"区域的任意标签
2. 自动执行搜索

#### 添加收藏
1. 在搜索结果中找到内容
2. 点击"⭐ 添加收藏"
3. 看到"收藏成功"提示

## 🐛 常见问题速查

### ❌ 无法加载插件
**解决**：
1. 确认 Chrome 版本 > 88
2. 开启"开发者模式"
3. 查看 `chrome://extensions/` 错误信息

### ❌ 后端服务无法连接
**解决**：
```bash
# 检查服务是否运行
python main.py

# 检查端口
netstat -ano | findstr :8000
```

### ❌ 搜索无结果
**解决**：
1. 确认已有收藏数据
2. 尝试其他关键词
3. 取消"只看收藏"选项

### ❌ 样式显示异常
**解决**：
1. 清除浏览器缓存（Ctrl+Shift+Del）
2. 重新加载插件
3. 检查网络请求
